UFC Fight Predictor

Python · scikit-learn · Streamlit

A fully local UFC fight predictor that trains a calibrated win-probability model on official UFC Stats career data and ranks value underdogs against live moneylines in a Streamlit dashboard — no cloud GPU, no paid hosting.

  • Built leak-free red−blue differential features (striking, takedowns, control time, form, reach) from prior-bout career averages only
  • Trained a HistGradientBoostingClassifier with a train/calibrate/holdout split evaluated on accuracy, Brier score, and log loss
  • Computed de-vigged market probabilities and expected value to surface underdogs the model rates above the market
